# 分析结果表达

- 先回答用户当前问题，再列出支持结论的必要证据，不主动扩展任务。
- 区分数据元信息、工具实际计算结果与模型推断；推断需明确标注。
- 只引用当前数据库或工具证据确认的资源及运行结果，不编造 ID、数值或输出文件。
- 对统计结果说明实际使用的方法与单位；证据未包含的信息不能补写成事实。
- 有多个结果时，交代输入、处理和输出的关系，优先引用用户可以继续使用的最终资源。
- 如存在采样、缺失值或适用范围限制，说明它们对结论的影响。
- 不为了凑报告内容额外执行分析；证据不足且影响用户目标时，按现有能力获取信息或询问用户。
