# Python 数据分析

利用现有 Python 执行接口补充必要的自定义处理。选择能完成当前目标的计算方式，保留支持结论的统计和可使用的输出。

## 执行接口

- 使用当前提供的 `python.execute` Schema；能力尚未提供时按项目工具发现规则查询。可用依赖以 Schema 中的运行环境为准，不能假设存在 Matplotlib、SciPy、ArcPy 或其他未列出的库，也不自行安装依赖。
- 调用参数是 `code` 和需要读取的 `dataset_ids`。`code` 是完整 Python 源码，不带 Markdown 围栏；`dataset_ids` 填当前已核验的数据集 ID。
- 执行环境注入 `datasets`，其结构为数据集 ID 到元信息的字典；通过 `datasets[id]["path"]` 读取数据。`output_dir` 和 `temp_dir` 是 `Path` 对象，分别用于交付文件和临时文件。
- 每次调用运行在独立进程，并创建新的输出目录。上次调用的变量、导入和内存对象不会保留；跨调用继续处理时使用返回的已登记资源，不能依赖上次的工作目录。
- 技能参考资料通过 `read_skill` 读取。读取代码示例不会执行，也不会将技能目录自动挂载到 Python 中；根据任务改写后将完整代码交给 `python.execute`。

## 计算与输出

- 只读取本次目标涉及的数据，按任务选择完整读取、分块或明确标注的抽样。准确总数、全局去重和全量统计不能由预览行数或样本结果代替。
- 将交付文件写入 `output_dir`，计算中的草稿和缓存写入 `temp_dir`；输出目录里的文件会被尝试登记为 Dataset，并发布为 Artifact，因此不要把临时调试文件留作交付。
- 使用格式对应的读写方式，保留必要的标识、CRS 和单位。源文件保持不变；输出文件名表达内容，避免包含不必要的用户数据。
- 通过 `print` 返回简短统计、必要样本和输出文件名，避免打印整表。需要稳定字段时可以输出 JSON，并将 NaN、NumPy 标量等转换成有效 JSON 值。
- 需要分组统计与 CSV 交付的完整示例时，按需读取 [表格统计示例](references/tabular-example.md)。示例的字段名和口径必须根据实际输入调整。

## 修正与验收

- 报错后区分字段或数据问题、代码错误、缺少依赖和权限限制。读取返回的错误与 `created_files`，定位原因后修正代码；权限限制不能通过其他执行方式绕过。
- 失败调用可能已经生成文件，但这些文件不一定完成登记；不能把文件存在、标准输出或退出码为零单独当作交付成功。不要原样重复可能产生副作用的代码。
- 对关键计算检查实际结果：例如关联关系、全量行数、聚合总量、单位、空结果以及非有限数值。检查选择与当前目标相关的指标，不增加无关分析或任意业务阈值。
- 写出结果后按需要重新读取，确认文件可用及关键结构；同时检查工具返回的登记警告和真实 Dataset、Artifact 引用。部分文件失败时明确已完成范围，不能自行编造引用。
- 已有证据足以支撑交付时结束。结果说明使用实际运行证据，失败修正和完成检查继续遵循项目已有机制。
